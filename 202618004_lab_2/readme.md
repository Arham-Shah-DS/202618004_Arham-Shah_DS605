## 📌 Assignment Overview

This project focuses on **data wrangling, analysis, feature engineering, and visualization** using the Titanic dataset.

The assignment covers:

- NumPy fundamentals
- Pandas data loading and inspection
- Data filtering and querying
- `groupby()` and aggregation
- Missing-value analysis and imputation
- Outlier detection using IQR
- Feature engineering
- Pivot tables
- Data visualization
- Statistical observations
